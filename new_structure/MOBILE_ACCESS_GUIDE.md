## 🔧 Troubleshooting

### If site doesn't load:

- ✅ **Check WiFi:** Both devices on same network?
- ✅ **Check URL:** Typed correctly? `http://192.168.1.124:8080`
- ✅ **Windows Firewall:** May need to allow Python through firewall
- ✅ **Router Settings:** Some routers block device-to-device communication

### Windows Firewall Fix:

1. **Search** "Windows Defender Firewall"
2. **Click** "Allow an app through firewall"
3. **Find** "Python" and check both boxes
4. **Or temporarily disable** firewall for testing
